# shot-sheet 共用规则

适用于 [CLI 主说明](../SKILL.md) 与 [Python 主说明](../PYSKILL.md)。

一次看两张以上截图，先拼一张审查图再打开。只处理本次授权的图片和输出路径，不覆盖他人的文件。

拼图和标注返回 `{"out", "width", "height"}`；媒体拼图另返回时长和采样时间，单独抽帧返回各帧路径、时间与尺寸。默认成品长边 ≤ 3900。核对返回尺寸，再用宿主读图工具打开 `out`，确认图片、顺序、中文标题和标注位置。文件生成成功不等于画面已验收。
找不到 CJK 字体时会发出警告并回退到 Pillow 默认字体，中文可能不可读；macOS 和 Linux 都要以实际成品为准。

输出路径必须不同于输入。`sheet`、`compare` 和 `annotate` 会覆盖指定输出，调用前确认输出属于本任务。抽帧不覆盖已有图片；媒体拼图拒绝输入输出相同，默认不覆盖已有成品，只有明确设置 `overwrite` 才覆盖。失败或取消后先核对输出是否完整，别把残留文件当作成功；只清理本次创建且已确认不需保留的产物。交付需要保留的成品路径并说明未验证的画面。
